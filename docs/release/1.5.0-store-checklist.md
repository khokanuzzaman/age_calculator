# Age Calculator 1.5.0 Store Checklist

Owner review required before submission. This checklist records review areas; it
does not assert legal or store-policy compliance.

## SDK inventory to review

- Firebase Analytics
- Firebase Crashlytics
- Google Mobile Ads
- Google User Messaging Platform (UMP)
- App Tracking Transparency (ATT)

## Google Play

- [ ] Confirm Data Safety answers against the shipped SDK versions and actual
  network behavior.
- [ ] Declare whether the app contains ads.
- [ ] Review Advertising ID declaration and Android `AD_ID` permission.
- [ ] Confirm privacy policy URL and that it describes ads, analytics,
  diagnostics, local personal data, and notifications accurately.
- [ ] Review notification permission and reminder behavior.
- [ ] Confirm target audience and App Content declarations.
- [ ] Upload current phone, tablet, and feature graphic screenshots as needed.
- [ ] Add reviewed 1.5.0 release notes.
- [ ] Run an Internal testing release on representative Android versions.
- [ ] Review and resolve relevant pre-launch report findings.

## Apple App Store

- [ ] Complete App Privacy answers for advertising, analytics, and diagnostics
  using the shipped SDK behavior.
- [ ] Review ATT prompt purpose, timing, and tracking disclosures. ATT is not
  Firebase Analytics consent.
- [ ] Confirm advertising and analytics disclosures match the actual build.
- [ ] Confirm diagnostics disclosures for Crashlytics match the actual build.
- [ ] Verify privacy policy URL and its current contents.
- [ ] Upload current iPhone and iPad screenshots.
- [ ] Add reviewed 1.5.0 release notes.
- [ ] Distribute through TestFlight and review device feedback/crashes.

## Store configuration

- [ ] Verify the Android package is `me.khokan.agecalculator`.
- [ ] Verify the iOS bundle ID is `me.khokan.agecalculator.ios`.
- [ ] Verify platform-specific AdMob app and unit IDs in their respective
  consoles; do not use production ads for developer-device interaction.
- [ ] Confirm the public Android and iOS store links resolve to the intended
  listings.
